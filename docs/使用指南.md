## 1. 系统简介

### 1.1 设计理念

传统的识字教学以反复抄写为主，孩子容易感到枯燥。俊宜识字系统采用 **阅读中识字** 的教育理念，通过 AI 生成孩子感兴趣的趣味短文，让生字自然出现在阅读语境中，配合遗忘曲线科学复习，让识字变得轻松有趣。

### 1.2 适用场景

- **家庭识字启蒙** — 家长每天录入当天学的生字，系统自动生成配套阅读材料
- **小学语文辅助** — 配合一年级语文课本进度，生成同步阅读练习
- **课外阅读拓展** — 根据孩子的兴趣话题定制阅读内容
- **自主学习跟踪** — 自动记录学习数据，导出成长报告

### 1.3 核心优势

| 特性 | 说明 |
|---|---|
| **拼音精准** | 使用 pypinyin 库注音，不是 AI 生成拼音，保证拼音准确率 |
| **课本排版** | 22号大字，拼音在汉字上方，模拟小学语文课本排版 |
| **兴趣驱动** | AI 根据孩子兴趣生成文章，保持阅读动力 |
| **科学复习** | 基于遗忘曲线，遗忘 1 次→3 次→5 次分级管理 |
| **AI 配图** | GLM-Image 自动生成封面插图，增强阅读趣味 |

## 2. 快速安装

### 2.1 环境要求

- **操作系统**: Windows / macOS / Linux
- **Python**: 3.10 及以上
- **Node.js**: 18 及以上
- **MySQL**: 8.2 及以上

### 2.2 数据库配置

```bash
# 全新安装：导入完整建表脚本
mysql -u root -p < sql/init.sql
```

### 2.3 数据库更新（已有数据升级）

从仓库拉取最新代码后，如果数据库结构有变更，需要运行迁移脚本。

**Windows 一键更新**：双击项目根目录的 `update_db.bat`，按提示输入数据库信息即可。

**手动更新**（所有平台通用）：

```bash
# 按序号顺序运行迁移脚本（每个脚本只运行一次，重复运行不会破坏数据）
mysql -u root -p junyi_word < sql/migration_001_voice_profiles.sql
mysql -u root -p junyi_word < sql/migration_002_voice_cloning.sql
mysql -u root -p junyi_word < sql/migration_003_learned_days_ago.sql
mysql -u root -p junyi_word < sql/migration_004_tier_system.sql
```

> 迁移脚本都是幂等的（用了 IF NOT EXISTS / IF EXISTS 等），不用担心重复运行。

### 2.4 后端启动

```bash
cd backend

# 安装 Python 依赖
pip install -r requirements.txt

# 配置 .env 文件（填入 API 密钥）
# DEEPSEEK_API_KEY=sk-xxx
# GLM_API_KEY=xxx
# PINECONE_API_KEY=xxx  # 可选，向量语义检索
# DB_HOST=127.0.0.1
# DB_USER=root
# DB_PASSWORD=your_password
# DB_NAME=junyi_word

# 启动后端服务 (默认端口 8000)
python run.py
```

### 2.5 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 启动开发服务器 (默认端口 5173 / 3000)
npm run dev
```

浏览器访问 `http://localhost:3000` 即可使用。

### 2.6 一键启动脚本

**Windows** (`start.bat`):
```bat
@echo off
start "Backend" cmd /c "cd backend && python run.py"
start "Frontend" cmd /c "cd frontend && npm run dev"
```

**macOS / Linux** (`start.sh`):
```bash
#!/bin/bash
cd backend && python run.py &
cd frontend && npm run dev &
wait
```

## 3. 功能详解

### 3.1 首页仪表盘

首页展示今日学习概况：

- **今日阅读中的已学生字** — 将当前文章中的字按学习日期分组显示，标注拼音和已学天数，用不同颜色区分批次
- **统计卡片** — 累计识字量、今日文章篇数、待复习遗忘字、待回答问题
- **兴趣热点** — 孩子近期关注的话题标签，附带趋势指示
- **最近问题** — 孩子提出的最新问题和回答状态

### 3.2 录入生字

支持三种录入方式：

1. **手动输入** — 逐个输入汉字，支持连续添加
2. **粘贴文本** — 复制整段文本，系统自动提取汉字去重
3. **语音录入** — 浏览器语音识别，说出词语实时提取生字（需 Chrome/Edge 浏览器）

录入后可选择是否立即生成阅读文章，支持指定主题。

### 3.3 AI 文章生成

- 根据已录生字自动生成适合一年级阅读的短小文章
- 支持自定义主题（如：春天、动物、学校、家庭）
- 每句话不超过 20 个字，段落之间有空行
- 自动调用 GLM-Image 生成封面插图
- 一天内可生成多篇文章

### 3.4 课本式阅读

文章阅读器采用 **小学语文课本排版**：

- 拼音在汉字上方，11px 字号
- 汉字 22px 字号，字与字之间有间隔
- 标点符号不注音
- 支持响应式布局，手机端自适应缩小
- 支持打印（打印时隐藏导航栏）
- **生字分级高亮**：当天学的字绿色高亮，3天内橙色高亮，7天内灰色标记
- **字库2 标记**：工作库中的字（巩固中）以黄色虚线下划线标记

### 3.5 点字发声与"认识/不认识"标记

点击文章中的汉字会触发两件事：

**发音反馈**：
- 任意汉字点击即读，不依赖家长，孩子可以自己探索
- 使用浏览器语音合成引擎（zh-CN），语速 0.85 适合儿童
- 点字瞬间有黄色放大闪烁动画反馈
- 支持**声音样版**替换合成音（见 3.11）

**浮动操作栏**：
- 点字后弹出"认识"/"不认识"浮动按钮栏，4秒后自动消失
- 家长根据孩子的实际掌握情况点击选择
- 点击"认识" → 该字在当前字库层级确认次数 +1，满足条件自动晋升
- 点击"不认识" → 记录为遗忘字，进入遗忘字复习列表

### 3.6 三层字库晋升体系

生字不再是一成不变的列表，而是动态流转的三层字库：

| 层级 | 名称 | 含义 | 晋升条件 |
|------|------|------|----------|
| **Tier 1** | 新字库 | 正在学习的生字 | 连续确认 3 次 → 升入 Tier 2 |
| **Tier 2** | 工作库 | 巩固中的字，需在不同文章中验证 | 在 3 篇不同文章中确认 → 升入 Tier 3 |
| **Tier 3** | 永久库 | 已掌握的字，不再主动推送 | 稳定保持，孩子的"识字财富" |

**晋升规则详解**：
- Tier 1 → Tier 2：同一篇文章中反复确认也可计数（连续 3 次即晋升）
- Tier 2 → Tier 3：必须跨越 3 篇**不同**文章，系统通过文章 ID 去重，防止同一篇文章反复确认刷满
- Tier 3：已掌握，标记"认识"只返回确认信息，不再变化

**视觉区分**：
- Tier 1 字：按学习天数分级高亮（当天=绿色、1-3天=橙色、4-7天=灰色）
- Tier 2 字：黄色虚线下划线（巩固中，等待跨文章验证）
- Tier 3 字：无特殊标记（已内化，不再需要视觉提醒）

### 3.7 多音字拼音修改

多音字（如"长"可读 cháng/zhǎng，"了"可读 le/liǎo）注音可能不准，可直接修改：

- **点击拼音文字** → 变为输入框 → 输入正确拼音 → 回车保存
- 修改后的拼音显示为**紫色 + 虚线下划线**，方便区分
- 修改后点字发音也会使用修正拼音（TTS 引擎按拼音文本朗读）
- 修改记录自动保存到浏览器本地存储，刷新不丢失

### 3.8 遗忘字复习

基于艾宾浩斯遗忘曲线的复习机制：

| 遗忘次数 | 等级 | 处理方式 |
|---|---|---|
| 1 次 | 活跃 (`active`) | 正常提醒复习 |
| 3 次 | 三次 (`3次`) | 重点复习，加大频率 |
| 5 次以上 | 五次以上 (`5次+`) | 强制复习，家长需关注 |

标记遗忘时需在复习页面勾选遗忘的生字，系统自动统计并更新等级。

### 3.9 好奇心追踪

记录孩子的提问，追踪兴趣演变：

- 输入孩子的原话，系统提取关键词和标签
- 标签自动关联到兴趣演变表，计算 30 天兴趣强度
- 趋势分为：上升 (`rising`)、稳定 (`stable`)、下降 (`declining`)
- 已回答的问题可关联到生成的文章

### 3.10 知识图谱

构建生字之间的知识网络：

- **相似关联 (`similar`)**: 字形相近的字
- **因果关联 (`cause_effect`)**: 有因果关系的概念
- **包含关联 (`part_of`)**: 部分与整体关系
- **反义关联 (`opposite`)**: 反义词
- **故事关联 (`story_connection`)**: 同一故事中出现

### 3.11 声音样版（自定义语音）

用真人录音替换机械的 TTS 合成音：

- **创建样版** — 在「声音样版」页面，创建如"李老师"、"妈妈"等样版
- **录制发音** — 点击字符卡片的录音按钮，使用麦克风朗读，自动保存
- **批量上传** — 支持拖拽上传音频文件（文件名 = 汉字，如 `春.webm`）
- **切换样版** — 在文章阅读页工具栏下拉框选择样版，已录音的字播放真人发音，未录音的字仍然使用合成音
- 录音使用 WebM 格式，浏览器原生支持播放

### 3.12 学习统计与导出

- 每日学习进度曲线
- 遗忘字分布统计
- 文章生成历史
- 支持导出 **CSV** 和 **JSON** 格式

### 3.13 向量语义检索（Pinecone）

当文章积累到一定数量（默认 50 篇），系统自动从 **MySQL 关键词匹配** 切换到 **Pinecone 向量语义检索**，提升记忆上下文的匹配精度。

**技术原理**：

| 组件 | 说明 |
|------|------|
| 嵌入模型 | `sentence-transformers` — `paraphrase-multilingual-MiniLM-L12-v2` |
| 向量维度 | 384 维 |
| 相似度度量 | Cosine similarity（余弦相似度） |
| 向量数据库 | Pinecone Serverless（AWS us-east-1） |
| 启用阈值 | 文章数 ≥ 50 篇（可通过 `VECTOR_DB_ARTICLE_THRESHOLD` 配置） |

**工作流程**：
1. 文章生成后，自动将「标题 + 前 800 字」向量化存入 Pinecone
2. 下次生成文章时，查询向量数据库找出语义最相似的历史文章
3. 将相关文章内容作为记忆上下文注入 AI prompt，实现个性化内容延续
4. 低于阈值时回退到 MySQL 关键词匹配，无需 Pinecone 也能正常运行

**配置**（`.env`）：

```env
# Pinecone 向量数据库（可选，不配置则使用 MySQL 关键词匹配）
PINECONE_API_KEY=your_key
PINECONE_ENV=us-east-1
PINECONE_INDEX_NAME=junyi-articles
VECTOR_DB_ARTICLE_THRESHOLD=50  # 文章数超过此值启用向量检索
```

**依赖安装**（可选）：

```bash
pip install pinecone-client sentence-transformers
```

> Pinecone 是可选的——不配置 API Key 时系统自动回退到 MySQL 关键词匹配，不影响正常使用。

## 4. 常见问题

### Q: 拼音不准确怎么办？

系统使用 pypinyin 库进行注音，准确率较高。如果发现多音字注音不准确，可以**直接点击文章中的拼音文字**进行修改，修改后发音也会自动纠正。详见 [3.7 多音字拼音修改](#37-多音字拼音修改)。

### Q: AI 文章生成失败？

检查 `.env` 中的 `DEEPSEEK_API_KEY` 是否正确，以及 API 账户余额是否充足。生成失败时会自动使用内置的预设文章模板。

### Q: 语音录入无法使用？

语音录入依赖浏览器的 SpeechRecognition API，需要使用 Chrome 或 Edge 浏览器，并允许麦克风权限。

### Q: 封面图生成失败？

封面图通过 GLM-Image（智谱 CogView）生成。如果 API Key 未配置或调用失败，阅读器将显示基于主题的表情符号替代。

### Q: 如何备份数据？

使用仪表盘的导出功能，可将全部学习数据导出为 CSV 或 JSON 文件。也可以直接备份 MySQL 数据库：

```bash
mysqldump -u root -p junyi_word > backup.sql
```

### Q: Pinecone 向量数据库必须配置吗？

**不是必须的**。Pinecone 是完全可选的增强功能：

- 不配置 `PINECONE_API_KEY` 时，系统自动使用 MySQL 关键词匹配查找相关历史文章
- 只有当文章数超过 `VECTOR_DB_ARTICLE_THRESHOLD`（默认 50 篇）且 API Key 有效时，才会切换到语义检索
- 即使配置了 Pinecone，也可以随时删除 API Key 回退到 MySQL 模式
- 依赖包也是可选的：`pip install pinecone-client sentence-transformers`，不安装不影响功能

## 5. 开发说明

### 5.1 技术架构

```
┌─────────────┐     ┌─────────────┐     ┌───────────┐     ┌───────────┐
│   React 18   │────▶│   FastAPI   │────▶│  MySQL 8.2│     │  Pinecone │
│  Ant Design  │◀────│  (Python)   │◀────│  (主数据库)│     │ (向量检索) │
│   (前端)     │     │   (后端)    │     └───────────┘     └─────┬─────┘
└─────────────┘     └──────┬──────┘                             │
                            │                                    │
                   ┌────────┴────────┐              semantic search
                   │  DeepSeek API   │              (paraphrase-multilingual
                   │  GLM-Image API  │               -MiniLM-L12-v2, 384d)
                   └─────────────────┘
```

### 5.2 API 路由

| 模块 | 路由前缀 | 说明 |
|---|---|---|
| 仪表盘 | `/api/dashboard` | 首页数据、统计、导出 |
| 生字管理 | `/api/characters` | 生字增删改查 + 三层字库标记 |
| 近期生字 | `/api/recent-chars` | 近期学过的字（返回字库层级 + 天数） |
| 文章管理 | `/api/articles` | 文章生成、查询、拼音标注 |
| 复习管理 | `/api/review` | 遗忘字标记、复习记录 |
| 好奇心 | `/api/curiosity` | 问题记录、兴趣演变 |
| 知识图谱 | `/api/knowledge` | 知识节点与关系 |
| 记忆上下文 | `/api/memory` | 学习历史上下文（用于 AI 生成） |
| 声音样版 | `/api/voice` | 真人录音上传与管理 |
| 静态音频 | `/api/audio` | 音频文件静态服务 |

### 5.3 安全提醒

- `.env` 文件包含 API 密钥，已加入 `.gitignore`，切勿提交到仓库
- 生产环境建议使用环境变量而非 `.env` 文件
- 建议定期更换 API 密钥
